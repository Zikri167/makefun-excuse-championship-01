A program that writes one funny one-line excuse an AI agent gives its human after something goes wrong — filed as a changelog entry.

Run it with Node 22:

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` — one line, 92 characters, no trailing newline.
